SIGMA - Versión HTML, CSS y JavaScript tradicional
===================================================

No requiere instalación, React, Node.js ni servidor.

INSTRUCCIONES
1. Descomprima el paquete.
2. Abra el archivo index.html con Chrome, Edge, Firefox o Safari.
3. Los datos se guardan en LocalStorage dentro de ese navegador.

ARCHIVOS
- index.html: estructura de la aplicación.
- styles.css: diseño visual y adaptación móvil.
- app.js: lógica, navegación, formularios y LocalStorage.

CATÁLOGOS
El rol Administrativa puede crear, editar, activar o desactivar camiones,
conductores, proveedores y categorías. Gerencia puede consultarlos y el rol
Técnico no tiene acceso al módulo. Solo los registros activos aparecen en los
formularios de anticipos y gastos.

NOTA SOBRE SOPORTES
El prototipo conserva el nombre del archivo seleccionado. Por las limitaciones y
el espacio de LocalStorage, no almacena el contenido binario completo de fotos o PDF.
